Key
T          temperature (°C)
t          time since the run started (s)
mixing time   when the reaction started (blue vertical line)
plateau    best-fit line through the slow part after the peak (orange)
T = m t + b   a straight line: m = slope (°C per s), b = T where the line hits t = 0
n          number of data points used for the plateau line

Final T
  extend the plateau line back to the vertical line
  final T = m × (mixing time) + b

initial T  average of the steady readings before mixing
raw max    highest reading in the run (lowest for NaHCO3)
ΔT         final T − initial T

How each gray box is worked out
A3  = A2 − A1
A5  = A4 ÷ 24.305 g/mol (Mg)
A8  = A7 − A6
A10 = mass × 4.184 × A8
      mass = A3 (+ A4 if box ticked)
A11 = −(A10 ÷ 1000) ÷ A5
      negative: heat was given off

B4  = B3 − B1
B5  = B3 − B2
B7  = B5 × B6 ÷ 1000
      treats g of HCl as mL (≈1.00 g/mL)
B10 = B9 − B8
B12 = B4 × 4.184 × B10
B13 = −(B12 ÷ 1000) ÷ B7

C3  = C2 − C1
C5  = C4 ÷ 84.007 g/mol (NaHCO₃)
C8  = C7 − C6 (negative)
C10 = mass × 4.184 × |C8|
      mass = C3 (+ C4 if box ticked)
C11 = +(C10 ÷ 1000) ÷ C5
      positive: heat was absorbed
