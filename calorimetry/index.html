Key
T          temperature (°C)
t          time since the run started (s)
T = m t + b   a straight line: m = slope (°C per s), b = T where the line hits t = 0
n          number of data points used for that line
rise       best-fit line through the steep part (blue)
plateau    best-fit line through the slow part after the peak (orange)

Where the lines cross
  m1 t + b1 = m2 t + b2   →   t = (b2 − b1) / (m1 − m2)
  then T = m1 t + b1   (this T is the final T)

initial T  average of the steady readings before mixing
raw max    highest reading in the run (lowest for NaHCO3)
ΔT         final T − initial T
